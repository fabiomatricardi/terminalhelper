GITHUB WIKI

### create the .gitignore
this file must be the first
If you created after the first init, clear the cache:
```bash
git rm -rf --cached .
```

### Init repo
```bash
git init
```

### Get the status of local repo
```bash
git status
```

### Add files to the staging area
```bash
git add .
git add -A  or git add --all
```

```bash
git commit -m "first commit"
```

```bash
git remote add origin https://github.com/fabiomatricardi/agents-studies.git
```

```bash
git push -u origin master
```
