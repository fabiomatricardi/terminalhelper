BIFROST and Bifrost-CLI

To install and run it you nee node.js installed

### Bifrost
After you have installed node.js, open the terminal everywhere and run:
```bash
# Install and run locally
npx -y @maximhq/bifrost
```
Bifrost must be run and invoked all time with the same command
> bifrost CLI can be invoked with simple `bifrost` as long is in the PATH


### bifrost-CLI
here the one for Bifrost-CLI:
```bash
npx -y @maximhq/bifrost-cli


⏱️ Downloading Binary: 100.0% (11 MB/11 MB))
✅ Checksum verified
✅ Installed bifrost to C:\Users\fabio\.bifrost\bin\bifrost.exe

To complete installation, add the following directory to your PATH:
  C:\Users\fabio\.bifrost\bin
```

> remember to set an environment variable for the bifrost-CLI app
> in my example is in `C:\Users\fabio\.bifrost\bin`
> bifrost CLI can be invoked with simple `bifrost` as long is in the PATH
